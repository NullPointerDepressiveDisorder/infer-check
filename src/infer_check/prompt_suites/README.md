# Bundled prompt suites

Each `.jsonl` line is one prompt: `id`, `text`, `category`, `max_tokens`, and
optionally an answer key (`answer_type` + `expected`). Prompts with an answer
key are graded for correctness; see `docs/interpreting-results.md`.

| Suite | Prompts | Answer keys | Source |
|---|---|---|---|
| `gsm8k` | 1319 | all | GSM8K test split (see below) |
| `adversarial-numerics` | 100 | 43, computed by `scripts/build_answer_keys.py` | infer-check |
| `reasoning`, `code`, `long-context`, `quant-sensitive`, `determinism` | 100 each | none | infer-check |

## GSM8K

`gsm8k.jsonl` is generated by `scripts/import_gsm8k.py` from the test split of
GSM8K: Karl Cobbe, Vineet Kosaraju, Mohammad Bavarian, et al., "Training
Verifiers to Solve Math Word Problems" (2021),
https://github.com/openai/grade-school-math. It is distributed under the MIT
License, Copyright (c) 2021 OpenAI.
